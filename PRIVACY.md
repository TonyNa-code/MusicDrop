# Privacy

MusicDrop runs locally. The application contains no telemetry, analytics, advertising SDK, account system or remote kill switch.

Network access occurs only after a visible user action to install a missing optional component:

- the pinned BtbN FFmpeg Release;
- the pinned optional QQ compatibility component.

Music files, platform databases, keys, output paths and buyer-license contents are not uploaded by MusicDrop. Settings and the optional DPAPI-protected EKey cache are stored under the current Windows user's local application-data directory.
