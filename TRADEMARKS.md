A commercial launch should first receive an appropriate name/logo clearance search.

The MIT license grants copyright permissions in the code. It does not grant a right to imply that a modified build is official, endorsed, supported, or security-audited by this project.

You may:

- truthfully say that software is “based on MusicDrop”;
- link to this project and use the name to describe compatibility;
- keep the original name/logo on an unmodified redistribution that clearly identifies its source and version.

If you materially modify or independently sell the software, use a distinct product name and logo, and state “based on the open-source MusicDrop project” where appropriate. Do not use the official logo in a way likely to confuse users about origin or support.
